Group subtotal computation

For each group, compute subtotal with your existing per-row helper:

const subtotal = useMemo(
  () => group.items.reduce((sum, item) => {
    return sum + calculateLineItemTotal(
      toNumber(item.quantity),
      toNumber(item.unitPrice),         // this is “cost” in your UI
      item.markupType, toNumber(item.markupValue),
      item.discountType, toNumber(item.discountValue)
    );
  }, 0),
  [group.items]
);
